# alejandrohinojosa2005.github.io

Personal website, built with [Quarto](https://quarto.org) and published with GitHub Pages from the `docs/` folder.

- Edit the `.qmd` pages (home is `index.qmd`); essays go in `writing/`.
- Render the whole site (RStudio's Build tab → Render Website, or `quarto render` in Terminal), then commit and push, including `docs/`.
- Fonts: Cousine and Arimo (SIL Open Font License), self-hosted in `fonts/`.
